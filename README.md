# The BatCave — Webchat

Public front-door page for the **#batcave** chat room on [HybridIRC](https://www.hybridirc.com/).
Visitors pick a nickname and join instantly — no account, no download.

- **Live page:** https://luckyrao.github.io/batcave-webchat/
- **Embed:** official HybridIRC / KiwiIRC client (`https://kiwiirc.hybridirc.com/#batcave`)

`index.html` is fully self-contained (one file). Search it for the `EDIT ME`
markers to change the room name, tagline, or house rules.

> This repo holds only the public landing page — no bot code or secrets.
